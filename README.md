# Feroxbuster Engine (`feroxbuster_engine`)

A Flutter package for high-speed recursive content discovery and web directory scanning.

## ✨ Features

- **Recursive Scanning**: Automatically recurses into discovered directory structures.
- **Ultra-Fast Speed**: Designed for high concurrency and quick response times.
- **Mobile Native**: Efficient memory and CPU utilization.

## 🚀 Installation

Add this package to your Flutter project's `pubspec.yaml`:

```yaml
dependencies:
  feroxbuster_engine:
    git:
      url: https://github.com/AbdoFawzi777/redops-hub.git
      path: packages/feroxbuster_engine
```

## 📝 Usage Example

```dart
import 'package:feroxbuster_engine/feroxbuster_engine.dart';

void main() async {
  print('feroxbuster_engine initialized successfully.');
}
```
