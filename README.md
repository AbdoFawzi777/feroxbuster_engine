# Feroxbuster Engine (`feroxbuster_engine`)

A Flutter package for high-speed recursive content discovery and web directory scanning.

## ✨ Features

- **Recursive Scanning**: Automatically recurses into discovered directory structures.
- **Ultra-Fast Speed**: Designed for high concurrency and quick response times.
- **Mobile Native**: Efficient memory and CPU utilization.
